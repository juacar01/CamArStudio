# Instalación de CamAR Studio

Para Windows 10 y 11 de 64 bits. Descarga el instalador desde la
[página oficial](https://juacar01.github.io/CamArStudio/).

## Instalar

1. Abre el archivo descargado.
2. Windows puede mostrar **«Windows protegió tu PC»**, porque el instalador todavía no lleva firma
   digital. Pulsa **Más información** y luego **Ejecutar de todas formas**.
3. Deja marcada la opción de la cámara virtual y termina la instalación.
4. Abre CamAR Studio desde el acceso directo.

Si tu antivirus bloquea el archivo, comprueba que lo descargaste de la página oficial.

## Usar la cámara virtual

1. En CamAR Studio, elige tu cámara y activa la **cámara virtual**.
2. En OBS Studio, añade una fuente **Dispositivo de captura de video** y elige
   **CamAr Studio Virtual Camera**. En Zoom, Discord u otros programas, selecciónala como cámara.

## Activar la suscripción

1. Abre la ventana de activación desde CamAR Studio.
2. Pega la clave que recibiste por correo al comprar y pulsa **Activar en este PC**.

La licencia vale para un PC. Para cambiar de equipo, desvincúlala primero desde esa misma ventana,
con conexión a internet.
